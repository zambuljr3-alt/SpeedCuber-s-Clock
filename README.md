🧩 SPEEDCUBER’S CLOCK

YOUR ULTIMATE SPEEDCUBING COMPANION

SPEEDCUBER’S CLOCK adalah aplikasi timer Rubik modern untuk para speedcuber yang ingin berlatih, meningkatkan kecepatan, dan mencatat setiap perkembangan mereka.

Dengan desain futuristik dan fitur latihan yang praktis, SPEEDCUBER’S CLOCK siap menemani perjalananmu menjadi speedcuber yang lebih hebat!

⚡ FITUR UTAMA

- ⏱️ Professional Cube Timer — Timer untuk mengukur waktu solve.
- 🔀 Scramble Generator — Membuat scramble Rubik secara otomatis.
- 🧠 Secret Scramble — Tantangan scramble khusus.
- 🏆 Personal Best (PB) — Catat rekor waktu terbaik.
- 📊 Ao5 & Ao12 — Pantau rata-rata waktu.
- 📚 Solve History — Simpan riwayat latihan.
- ⏳ Inspection Mode — Persiapan sebelum solve.
- 📱 Remote Timer Display — Hubungkan dua HP menggunakan Room Code.
- 🎯 Session Manager — Kelola sesi latihan.

🌐 REMOTE TIMER DISPLAY

Jadikan HP kedua sebagai layar timer tambahan seperti Rubik Timer Stand!

🎮 SIAP MENJADI SPEEDCUBER?

Latihan lebih teratur, pantau perkembangan, dan kejar Personal Best berikutnya.
